# 1x04 — Cryptographic Foundation

## Project Overview

This project develops practical cryptographic security skills for MedDefense Health Systems, building on Projects 1x00 through 1x03.

## Objectives

- Identify encryption weaknesses in clinical and business systems.
- Understand symmetric encryption, asymmetric encryption, and hashing.
- Practice OpenSSL, TLS, X.509 certificates, and LUKS.
- Evaluate encryption at rest, in transit, and in use.
- Document commands, outputs, validation, and security recommendations.

## Deliverables

- [Task 0 — Crypto Inventory](0-crypto_inventory.md)

## Evidence and Safety

All findings must reference documented evidence. Cryptographic changes must be tested in a lab before any authorized production deployment.
